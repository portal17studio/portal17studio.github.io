Privacy Policy

Last updated: October 11, 2026

🔒 The short version: Portal17 Studio runs on your own computer. We don't collect, receive, sell or have any access to your flows, variables, passwords, files or browsing. The app has no analytics and no account. It only connects to the services you point it at.

This policy explains what happens to your data when you use the Portal17 Studio desktop app, get it from the Microsoft Store, or visit this website (portal17studio.com). It applies to every language the app is available in.

What stays on your computer

  • Flows (.portal files) are saved wherever you choose. We never receive a copy.
  • Variables, constants and tables live in the app while it runs and are written only to files you pick (Excel, CSV…).
  • Passwords and API keys are kept encrypted in the Secrets vault on your computer. Flows only contain a reference such as [secret:name], and passwords typed while recording go straight to the vault.
  • Run history (when each flow ran, how long it took, how it ended and the variables at the end) is stored in your user folder.
  • Failure reports are saved locally when a step fails: screenshots of the screen and of the web page, the step's settings (with secrets hidden) and a list of what the program window contained. Screenshots may show whatever was on your screen at that moment. Only the 20 most recent reports are kept, and you can delete the folder at any time.
  • Scheduled flows and triggers are registered on your computer (Windows Task Scheduler, a shortcut in your Startup folder for the background service). Nothing about them is sent to us.

Connections the app makes — only when you use them

Portal17 Studio has no servers of its own and sends nothing to us. It only connects to the places your flows and settings tell it to:

  • Websites your flows visit, in Edge, Chrome or the browser built into the app. What you do there is between you and those websites.
  • APIs, databases and email servers you configure in nodes such as Call API, SQL Query and Send Email, using the addresses and credentials you provide.
  • Email triggers read the inbox you choose (Outlook on your computer, or an IMAP server you configure) to start flows when a message arrives. The IMAP password is kept in the encrypted vault, and attachments are saved (if that option is on) into the app's folder in your user profile so the flow can use them.
  • Webhooks are received by a small server running on your computer. If you choose to give it a public address, the connection goes through a Cloudflare tunnel (the free cloudflared tool, which you install yourself or download from Cloudflare's official GitHub page when you ask). That traffic is then handled by Cloudflare under its own privacy policy.
  • Check this computer (Settings → General) tests the internet connection by opening portal17studio.com/sandbox once, like any visit to this website.

There is no telemetry: the app includes no analytics, crash-reporting or usage-tracking components of any kind.

Microsoft Store

If you install Portal17 Studio from the Microsoft Store, Microsoft collects standard account, purchase and diagnostic information as part of running the Store and Windows — the same as for any other Store app. That data is handled under Microsoft's own commitments, not ours. See the Microsoft Privacy Statement.

This website

portal17studio.com is a static site with no backend, no accounts, no analytics and no cookies. The Playground and the practice Sandbox run entirely in your browser: nothing you click, type or “submit” there is sent to us or stored, and it all resets when you reload the page.

The site is hosted on GitHub Pages, which, like any web host, may record technical information such as IP addresses to operate and protect the service (see GitHub's privacy statement). The directory badge in the footer is an image loaded from saasbrowser.com.

Children's privacy

Portal17 Studio is not directed at children under 13, and we do not knowingly collect personal information from anyone. Since neither the app nor this website collects personal data, this holds regardless of age.

Changes to this policy

If this policy changes — for example, if a future version adds an optional online feature — we'll update this page and the “Last updated” date above.
