RECORD THE WAY YOU WORK Illustrative demo

You do the task.
The recorder connects the steps.

Real controls, not pixelsButtons, fields, boxes and lists are found by what they are, so steps keep working when a window moves or resizes.
Help when interfaces changeRecorded steps keep fallback information and a snapshot of the control to help locate it again when an interface changes. Review and test a repaired step.
Recorded in sequenceMouse and keyboard are captured on their own and processed in order, even in heavy apps. Type as fast as you like.
Recognized password fieldsPassword fields recognized by the recorder use encrypted Secrets references such as [secret:…]. Review other captured text and images before sharing a flow.

DATA THAT MOVES WITH THE FLOW

Read it. Transform it.
Use it in the next step.

Bring together values from a page, a desktop control, an API or a database. Keep them in the Data Store and reference them wherever the process needs them.

  • Read from the sourceExtract text, read application controls, or select fields from a JSON response.
  • Make values usableTrim text, replace with regex, parse numbers and reformat dates.
  • Put the result to workFill another app, write an Excel or CSV file, or send an email.
