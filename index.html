Everything you need

Automation that reads like a flowchart

Every node exists because a real, repetitive task needed it.

Record

Browser + Windows in one recording

Clicks, fields, boxes, lists, drag and drop and shortcuts — on websites and in any program — become nodes. Choose what to record in Settings.

Copy & paste that follows the data

Ctrl+C reads the value live on every run and Ctrl+V types it — from a web page into a desktop app, or the other way round.

Recordings that clean themselves

Clicks before typing disappear, waits and keys are merged, and filling the same form three times becomes one loop over a table.

File uploads

Hand one or several files to any “Choose file” on a page, hidden inputs included, with no Windows dialog to get stuck on.

Keys & shortcuts

Enter to search, Esc to close, arrows through suggestions, Ctrl+S to save — recorded as you press them and replayed even with the browser hidden.

Point and pick

Hover any control in any program and press Ctrl. Programs that draw their own interface? Point at a picture of the button instead.

Build

Visual flow builder

Drag nodes onto a canvas and wire them together. Every step is a box you can read, change and test on its own.

Branching & loops

If/Else, If Exists, multi-way Switch, loops with exit conditions, and For Each over every row or every element on a page.

Waits that know what to wait for

Wait until a message, a button or a window appears — or until a “loading…” goes away — instead of guessing seconds.

Any Windows program

Click, type, tick, choose and read in desktop apps by their real controls. Launch programs, wait for windows and send keys too.

Reusable sub-flows

Call another flow as a single step and pass it values — build “log in” once and use it everywhere.

Run JavaScript

The escape hatch for everything else: run a snippet on the page and save what it returns into a variable.

Data

Read Excel & CSV

Load a sheet and let For Each go row by row — every column becomes a variable you can drop into any step.

Export to Excel & CSV

Build a real .xlsx or CSV one row per pass of a loop, with the headers written for you.

Clean & transform

Trim, change case, pull the number out of “1.234,50 €”, replace with patterns or reformat dates — one node, no code.

Databases

Query PostgreSQL or SQL Server out of the box — or MySQL, Oracle and almost any other database by dropping in its driver file.

REST APIs

Call any HTTP API and pull fields straight out of the JSON — the dependable way to get data when a site blocks scraping.

Email & files

Send results with attachments, zip folders and save screenshots — the last mile of most reports.

Run by itself

Scheduler

Run a flow at a set time, even with the app closed. Override its constants per task, so one flow runs at 8:00 for Madrid and 9:00 for Barcelona.

Triggers

Start a flow when a file lands in a folder, an email arrives in Outlook or any IMAP inbox, you press a shortcut or Windows starts — or from another app with a signed webhook.

Runs in the background

Triggers keep watching while the app is closed and can start with Windows — the flows just happen.

Command line

Start any saved flow unattended from a script or another tool, with no window at all.

Encrypted secrets

Passwords and API keys stay encrypted on your PC and flows only say [secret:name] — share a flow without leaking a credential.

Tidy big flows

Collapsible groups, sticky notes, a tab for every open flow and automatic layout keep a 100-step flow readable.

Built not to break

Websites change. Programs update. Your flows keep going.

Most automations die the day a button moves. Portal17 Studio expects it.

  • Steps that repair themselvesEvery step remembers what it found. When a page or a program changes, it finds the same thing again, carries on, and suggests the fix — one click to apply.
  • Your rules when something failsPer step: retry a few times, stop, carry on, or follow its own error path to log it and move on to the next row.
  • See exactly whyThe run history keeps every failure with screenshots, the step's settings and what was on screen — and a button that takes you straight to the node.
  • Fix it without starting overBreakpoints, step by step, “Run from here” and “Run only this node” — try the change on what is already open.
  • A health check for your PCOne click tests screen capture, program controls, keyboard and connection, and says in plain words what works.
