What is Portal17 Studio?+

Portal17 Studio is no-code RPA (robotic process automation) software for Windows. It automates repetitive tasks in web browsers and desktop applications: filling in web forms from Excel, copying data between websites and Windows programs, collecting web tables into a spreadsheet, reading emails and PDF invoices, and sending reports on a schedule.

How is it different from UiPath or Power Automate Desktop?+

Like them, it records and replays work in the browser and in Windows apps. Portal17 Studio is made for individuals and small teams: you install it from the Microsoft Store, your flows run on your own PC, and there is no server or orchestrator to set up.

Can I try it for free?+

Yes. Portal17 Studio is a paid Windows application with a free trial through Microsoft Store. Review the current price and trial conditions in the Store before installing or buying.

Do I need to know how to code?+

No. Record yourself doing a task or build a flow by dragging actions onto the canvas and connecting them.

Does it work with desktop apps?+

Yes. Automate browser pages and Windows applications in the same flow, including typing, clicks, shortcuts and reading controls.

Where do my flows and secrets live?+

Your flows and encrypted secrets stay on your computer. The process can connect to the websites and services you choose.
