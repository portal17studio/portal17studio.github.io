THE ACTIONS PANEL

The right building block.
For every part of the job.

Explore the tools behind the canvas: record and build, work with data, or manage execution.

Visual Flow Builder

Drag nodes onto a canvas and wire them together — no coding, just building blocks.

Records Browser + Windows

Do the task once — on a website or in any Windows program — and every click, field, box, list, drag and shortcut becomes a node. Pick what to record in Settings.

Branching & Loops

If/Else, If Exists, multi-way Switch, loops with exit conditions, and For Each over every element that matches a selector — scraping a whole product list is one loop.

Database Queries

Pull data straight from PostgreSQL or SQL Server out of the box — or plug in the driver for MySQL, Oracle, or any other JDBC database yourself.

Call REST APIs

Fetch data from any HTTP API and pull fields straight out of the JSON into variables — the dependable way to get data when a site blocks scraping.

Excel & CSV Export

Capture values as you go, reuse them anywhere in the flow, and build up a real Excel (.xlsx) or CSV file row by row as your loop runs.

Clean & Transform Data

Scraped text is messy. Trim it, change case, extract the number out of "1.234,50 €", replace with regex, or reformat dates — one node, no code.

Run JavaScript

The escape hatch for everything else: run a JS snippet on the page and save what it returns into a variable — read attributes, count elements, compute anything.

Encrypted Secrets

Keep passwords and API keys encrypted on your machine and reference them as [secret:name]. Passwords typed while recording land here automatically — share a flow without leaking a credential.

Windows App Automation

Click buttons, fill fields, tick boxes, choose from lists and read text in any desktop app by its real controls. App draws its own interface? Point at a picture of the button instead.

Keys & Shortcuts

Enter to search, Esc to close, arrows through suggestions, Ctrl+S to save — recorded as you press them and replayed even in the invisible browser.

Copy & Paste That Follows the Data

Ctrl+C and Ctrl+V while recording become a variable, so every run copies the current value — from a web page into a desktop app, or the other way round.

Triggers

Start a flow by itself when a file lands in a folder, an email arrives in Outlook or any IMAP inbox, you press a shortcut or Windows starts, or from any other app with a signed webhook. They can keep running in the background with the app closed.

Recordings That Clean Themselves

Stop recording and the flow is tidied for you: clicks before typing disappear, waits and keys are merged, and filling the same form three times becomes one loop over a table.

Waits That Know What to Wait For

Wait until a message, a button or a table appears — or until a “loading…” goes away — instead of guessing seconds.

File Uploads

Hand one or several files to any “Choose file” on a page, hidden inputs included, with no Windows dialog to get stuck on.

Know Why a Step Failed

Every failure leaves a report: a screenshot, the step and its settings, what was being looked for and what the window actually had. A built-in check tests automation on your PC in one click.

Debug Without Starting Over

Breakpoints, step-by-step runs and “Run from here” on any node: try the end of a long flow on what is already open, without repeating the start.

Groups & Sticky Notes

Organize big flows into collapsible groups and leave yourself sticky notes as you go.

Parameterized Scheduler

Run a saved flow automatically at a set time — even while Portal17 Studio is closed. Override a flow's constants per task, so the same flow runs at 8:00 for Madrid and 9:00 for Barcelona.

Reusable Subflows

Use Call Portal to run another saved flow. Pass different constants to the same process instead of rebuilding it for every project.

Tables & Parameters

Keep constants, live variables and tables together in the Data Store. Fill a form once for each row and reuse values across your flow.

Recovery on Your Terms

Choose what happens when a node fails: retry, stop, continue, or follow a separate error path. Build recovery into the process.

Automatic Selector Repair

Recorded steps keep fallback information about the element you picked, helping the flow find it again when the interface changes.
